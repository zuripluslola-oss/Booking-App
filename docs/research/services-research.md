# BookKit Service Catalog Research — 10 Professions

What each trade actually books: real services, realistic durations, standard add-ons, deposit norms, and intake needs. Durations reflect how the businesses actually run, not best-case.

- **SMS reminder the day before is the single highest-impact no-show reducer.** It should be on by default for every trade.

---

## 1. Barber
Fast turnover, walk-in heavy, rarely needs intake or deposits.

| Service | Duration | Notes |
|---|---|---|
| Line-up / edge-up | 15 min | quick, high-frequency |
| Skin fade | 30–45 min | core service |
| Beard trim + hot towel | 20–30 min | common add-on to a cut |
| Kids cut | 30 min | |
| Cut + beard combo | 45–60 min | |

**Add-ons:** hot towel, beard oil, designs/parts, gray blending.
**Deposit:** rare. Walk-ins toggle matters more than deposits here.
**Intake:** none. **Recurring:** high value — many clients rebook every 2–3 weeks.

## 2. Hair Salon
Color drives long, variable appointments; product recommendations at checkout.

| Service | Duration | Notes |
|---|---|---|
| Blowout | 45 min | |
| Gloss + trim | 60 min | |
| Highlights | 90 min | |
| Balayage | 2.5 hrs | often 150 min+ |
| Full color | 105 min | |

**Add-ons:** toner/gloss, Olaplex/bond treatment, deep conditioning, extensions.
**Deposit:** common for color services (time-intensive); many salons hold a card on file.
**Intake:** allergy/patch-test note for color; photo reference helpful. **Multi-stylist:** yes.

## 3. Braider
Long appointments (half-day to full-day), and the "hair included?" question is central to booking.

| Service | Duration | Notes |
|---|---|---|
| Large / jumbo box braids | 3–5 hrs | |
| Medium box / knotless | 5–8 hrs | |
| Small box / knotless | 8–14 hrs | plan a full day |
| Cornrows / feed-in | 2–4 hrs | |
| Takedown / removal | 1–2 hrs | separate bookable service |

**The defining booking question — "Is hair included?"** For knotless, hair is commonly *included* in the price in natural colors (1, 1B, 2, 4); custom colors are a paid add-on (+$5–10), ombré more (+$25). For crochet/locs, hair is often *not* included. Booking flow must ask this and adjust line items.
**Add-ons:** color hair, ombré, boho curls, beads/accessories, length upcharge (waist/butt-length).
**Deposit:** standard, non-refundable, applied to balance — typically **$20–75** (some scale $20–300 by service). Common 48–72 hr reschedule notice.
**Intake:** inspo photo; "arrive with clean, detangled, product-free hair" note. Gallery organized by style *and* length.

## 4. Loctician
Consultation-first culture, especially for starter locs; retwist is the recurring backbone.

| Service | Duration | Notes |
|---|---|---|
| Loc consultation | 30 min (often free or $50, credited) | frequently *required* before starter locs |
| Starter locs | 3–8 hrs | price varies by size/length/density |
| Retwist (palm roll / comb) | 2–4 hrs | recurring every 4–6 weeks |
| Interlocking | 2–5 hrs | holds 6–10 weeks |
| Instant locs / extensions | 4–8+ hrs | |
| Repair / detox | varies | |

**Consultation norm:** starter locs, instant locs, and extensions commonly require a **$50 consultation** before the main appointment can be booked — build a consult gate.
**Add-ons:** boho/two-strand-twist styling, color, shampoo (sometimes included).
**Deposit:** standard, ~$50, non-refundable, applied to balance.
**Signature feature:** progress-photo timeline across the loc journey (starter → budding → teen → mature). **Recurring:** retwist plans (monthly).

## 5. Wig Specialist
Product catalog + install appointments — a hybrid of e-commerce and booking.

| Service | Duration | Notes |
|---|---|---|
| Consultation / measurements | 20–30 min | |
| Custom unit build | multi-day (not a chair appointment) | order, not time-slot |
| Coloring / bleaching knots | 1–3 hrs | |
| Customization (cut, pluck, cap) | 1–2 hrs | |
| Install | 1–2 hrs | bookable appointment |
| Maintenance / revamp | 1–2 hrs | |

**Split model:** ready-to-ship wigs and custom orders behave like **products** (storefront, ship), while install/color/maintenance are **appointments**. The pack needs both.
**Measurements:** collect at booking (head circumference, etc.) or in person.
**Deposit:** common for custom builds (materials).
**Intake:** desired length/density/color, photo reference.

## 6. Nail Studio
Short, high-volume, Instagram-driven. Removal and art are the money add-ons.

| Service | Duration | Notes |
|---|---|---|
| Express manicure | 15–20 min | |
| Gel manicure | 45–60 min | |
| Acrylic full set | 90 min (45 min–2 hr range) | |
| Fill-in | 45–60 min | recurring every 2–3 weeks |
| Gel pedicure | 45–60 min | |
| Spa / luxury pedicure | 60–90 min | |

**Add-ons that change duration (must be priced as time):**
- Nail art: +10–30 min (simple to elaborate; full elaborate set can add an hour)
- Removal / soak-off of old product: +15–30 min *before* the new service
- Chrome/ombré, French, embellishments.
**Deposit:** small, ~$20, or card on file — mainly to curb the easy-to-forget short appointment.
**Intake:** design reference photo; gel vs acrylic, shape, length. **Recurring:** fills.

## 7. Esthetician / Spa
Health intake matters; memberships are the retention engine.

| Service | Duration | Notes |
|---|---|---|
| Express facial | 30 min | pre-event refresh |
| Signature facial | 60 min | the standard; ~5–10 min consult built in |
| Deluxe facial (LED/microderm) | 75–90 min | |
| Chemical peel | 45–60 min | |
| Dermaplaning | 45 min | |
| Waxing | 15–45 min | by area |

**Intake (required):** skin type, main concern, pregnancy/nursing, allergies/sensitivities (retinol, fragrance), current actives. Peels especially need contraindication screening.
**Deposit:** often none for facials; card on file common.
**Memberships:** monthly facial membership is the core recurring model — build plans.
**Note:** first-timers → default 60 min so there's time for consultation.

## 8. Massage Therapy
Session length is the product; medical intake and pressure are the two must-ask fields.

| Service | Duration | Notes |
|---|---|---|
| Targeted / focused | 30 min | one small area |
| Standard full body | 60 min | **industry standard**, most-requested |
| Therapeutic | 90 min | full body + focused deep work |
| Extended | 120 min | luxury / chronic pain |
| Prenatal, hot stone | 60–90 min | longer default for setup/pace |

**Intake (required):** pressure preference (light→deep), focus areas (multi-select), injuries/conditions, pregnancy. First-timers benefit from a slightly longer session for assessment.
**Buffer note:** advertised time often includes ~10 min intake/dress; decide whether your "60 min" is hands-on or total, and expose it. Build buffer padding after each session.
**Deposit:** card on file / cancellation fee common; deposits less so.
**Room selection:** optional.

## 9. Tattoo Studio
The most structured booking: consultation, reference uploads, and a real deposit are all standard.

| Service | Duration | Notes |
|---|---|---|
| Consultation | 15–40 min (often free, or fee credited) | discovery + design talk |
| Flash / small piece | 30–60 min | |
| Fine line | 1–2 hrs | |
| Half-day session | 3–4 hrs | |
| Full-day / custom sleeve | 6–8 hrs | multi-session projects link appointments |
| Cover-up | 1.5–3 hrs | |
| Touch-up | 30–60 min | |

**Consultation:** commonly required before a custom session is confirmed.
**Deposit — the strongest norm of any trade:** **non-refundable, applied to the final balance.** Typically a **fixed $50–200** or **20–50% of estimated cost** (30% common for large custom). Standard **48–72 hr** reschedule notice or the deposit is forfeited; forfeited on no-show, late arrival (often 15–30 min), or major design change. Deposit valid ~12 months, non-transferable between artists.
**Intake (required):** reference images, placement, size estimate, and health/consent + aftercare acknowledgment. Valid photo ID at appointment.
**Multi-artist:** clients pick artist by style. **Portfolio-first** presentation.

## 10. Makeup Artist
Event-driven, bridal is the anchor; trials and travel fees are the specifics.

| Service | Duration | Notes |
|---|---|---|
| Trial (bridal) | 60–90 min | booked ahead of the event |
| Bridal day-of | 60 min/face | |
| Bridesmaid / party (each) | 30–45 min | group bookings |
| Event / photoshoot look | 45–60 min | |
| Add lashes | +15 min | |

**Bridal packages:** bride-only, bride + party, full day — bundle multiple faces with timing.
**Mobile / on-location:** offered vs studio-only; **travel fee** auto-calculated or flat.
**Deposit:** standard to hold event dates (~$50 or % of package), especially bridal.
**Intake:** occasion, desired look, location, lashes, inspo photos. **Lead time:** longer reminder (2 days) since events are planned.

## How this maps into the product

**Service object needs at minimum:** name, category, duration (minutes), price (or "from"), deposit (fixed or %), whether it gates on consultation, whether it requires uploads, and which add-ons attach.

**Add-ons are first-class, not notes** — because they change *time and price*. Nail removal (+15–30 min), braid color (+$10), length upcharge, lashes (+15 min), boho styling: each is a toggle that adjusts the appointment length the calendar reserves and the total charged.

**Deposit posture by trade (default on/off):**
- **Deposit-standard:** Tattoo (strong, often %), Braider, Loctician, Makeup (events), Wig (custom).
- **Card-on-file / light:** Salon color, Nail, Massage, Spa.
- **Usually none:** Barber.

**Consultation gate (default on):** Tattoo (custom), Loctician (starter/instant/extensions). Optional elsewhere.

**Required intake (default on):** Massage and Esthetician (health), Tattoo (reference + consent). Style-detail intake (helpful, not blocking): Braider, Nail, Loctician, Makeup, Wig.

**Recurring model by trade:** Barber (2–3 wk cuts), Loctician (4–6 wk retwist), Nail (2–3 wk fills), Spa (monthly membership). Surface "rebook" prominently for these.

This is the catalog that lets BookKit cover what Booksy/Acuity/Square cover *per trade* — same booking engine underneath, defaults that feel hand-built for each profession.
