# Website Conversion Philosophy

Core Principle:
We are not building generic websites. We are building conversion funnels dressed as premium profession-specific websites.

Every section must justify its existence by improving booking conversion, trust, average order value, or repeat business.

Template Rules:
- Every profession has its own customer journey.
- Templates are based on research into successful businesses in that profession.
- Businesses customize branding, content, colors, media, and approved layout options.
- Businesses can add, remove, hide, show, and reorder supported sections.
- Businesses cannot break the design system.
- Every template is mobile-first and booking-first.

Success metrics:
- Booking conversion
- Consultation conversion
- Average booking value
- Repeat booking rate
- Membership/package adoption
- Review generation
